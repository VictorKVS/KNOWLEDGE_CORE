# Languages

This layer contains language-specific engineering knowledge for Python, Go and C++.

The goal is not to teach syntax in isolation. Each language section must help an engineer or agent answer:

- what the construct or technique is;
- when it should be used;
- when it should be avoided;
- what alternatives exist;
- what the performance, reliability and security trade-offs are;
- which official, academic or otherwise authoritative sources support the conclusion;
- how the choice behaves in realistic tests and benchmarks.

## Shared topic model

Each language should progressively cover:

1. language fundamentals;
2. numeric and scalar types;
3. collections and data structures;
4. memory and object model;
5. error handling;
6. concurrency and parallelism;
7. networking and I/O;
8. testing;
9. performance;
10. security;
11. packaging/build/deployment;
12. idioms and pitfalls;
13. typical engineering problems;
14. alternatives across Python, Go and C++.
