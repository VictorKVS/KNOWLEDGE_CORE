# Python Engineering Knowledge

**Role in the ecosystem:** AI orchestration, automation, backend systems, data workflows, research tooling and rapid product engineering.

Python knowledge in this repository is evidence-oriented rather than syntax-oriented.

## Knowledge map

- Numeric types and precision
- Collections and data structures
- Object and memory model
- Iterators and generators
- Exceptions and failure handling
- Typing
- Async I/O
- Multiprocessing and concurrency
- Networking
- Testing
- Packaging and environments
- Performance and profiling
- Secure coding
- Common production pitfalls
- Cross-language alternatives

## Decision questions

Typical cards should answer questions such as:

- `list` vs `tuple` vs `set` vs `dict`?
- `float` vs `Decimal` vs integer minor units?
- threads vs asyncio vs multiprocessing?
- dataclass vs TypedDict vs Pydantic model?
- Python service vs Go service vs C++ native component?

## Evidence priority

1. Python Language Reference / standard library documentation / PEPs;
2. relevant standards and specifications;
3. peer-reviewed research and recognized textbooks;
4. reproducible benchmarks and experiments;
5. mature framework/vendor documentation;
6. community sources only as supporting evidence or hypotheses.
