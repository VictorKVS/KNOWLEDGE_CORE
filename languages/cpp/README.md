# C++ Engineering Knowledge

**Role in the ecosystem:** systems programming, high-performance components, algorithms, native integrations and performance-sensitive security tooling.

## Knowledge map

- Fundamental types and numeric behavior
- References, pointers and ownership
- RAII and resource lifetime
- Containers and STL algorithms
- Templates and generic programming
- Error handling
- Concurrency and atomics
- Memory model
- Networking and I/O
- Build systems and dependencies
- Testing and sanitizers
- Profiling and performance
- Undefined behavior and safety
- Secure coding
- Interoperability with Python/Go
- Cross-language alternatives

## Decision questions

Typical cards should answer:

- stack vs heap allocation?
- vector vs deque vs list?
- raw pointer vs smart pointer vs reference?
- exception vs error value?
- mutex vs atomic?
- C++ native component vs Go service vs Python orchestration?

## Evidence priority

1. ISO C++ standard and cppreference as a navigation aid, with claims traced to normative or official sources where needed;
2. WG21 papers, compiler documentation and official toolchain material;
3. relevant standards and RFCs;
4. peer-reviewed systems/security research and recognized textbooks;
5. reproducible benchmarks, sanitizers and experiments;
6. mature engineering sources as secondary evidence.
