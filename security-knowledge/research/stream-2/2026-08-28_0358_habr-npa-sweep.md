## New machine rules from this pass

1. `standard designation + official title` is identity-critical; a structured code list with a correct designation but wrong title is rejected as evidence.
2. Federal-law number alone is never a stable ID: the same number can recur in different years (`259-ФЗ` is a concrete confirmed example).
3. A source that explicitly contains model-synthesized normative definitions cannot be promoted to evidence merely because it cites real standards.
4. GitHub fulltext discovery and official-currentness verification remain separate gates.
