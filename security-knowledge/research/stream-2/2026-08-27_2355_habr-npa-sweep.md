2. `ГОСТ Р ИСО/МЭК 13335-1-2006` remains `Действует` in the Rosstandart catalog even though parts 3/4 from the same historical family were previously confirmed as superseded by 27005. Do not infer family-wide supersession from part 3/4 status. The 2007 correction must be represented separately in its change chain.
3. The Common Criteria block in this fixed GitHub snapshot has four strong binary candidates: `15408-1-2012`, `15408-2-2013`, `15408-3-2013`, and companion methodology `18045-2013`. Rosstandart currently marks all four as active. For 15408-1/-2/-3 the predecessor editions are explicitly recorded as replaced; for 18045 the 2008 edition is explicitly replaced by 2013.
4. `ГОСТ Р 56545-2015`, `56546-2015`, and `21827-2010` are all currently marked `Действует` by Rosstandart, so these repository binaries are high-priority acquisition candidates once internal PDF identity is verified.

## New blocker

GitHub metadata exposes path/blob SHA/size for the PDFs, but the connector cannot decode the binary PDF blob as UTF-8, and the current runtime could not retrieve raw GitHub binary bytes for local title-page inspection. Therefore none of these artifacts is promoted to `IDENTITY_INTERNAL_VERIFIED` in this pass. Required next gate: acquire bytes through an allowed binary path, hash locally, inspect title page/designation/title/year, then compare to official catalog identity. This is deliberately separate from `OFFICIAL_STATUS_VERIFIED`.
