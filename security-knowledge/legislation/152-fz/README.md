# Корпус знаний по 152‑ФЗ

Рабочая зона сбора, проверки и связывания материалов по законодательству РФ о персональных данных.

> Состояние на 2026-08-19: стартовый реестр. Наличие записи не означает, что актуальная редакция уже подтверждена. Для юридических выводов используется только источник со статусами `official_url_verified` и `version_verified`.

## Что собираем

1. Федеральные законы и их изменяющие акты.
2. Постановления Правительства РФ.
3. Приказы Роскомнадзора, ФСТЭК и ФСБ.
4. Разъяснения, формы уведомлений, реестры и контрольные материалы регуляторов.
5. Судебную и административную практику.
6. Методические документы, научные статьи и проверенные профессиональные комментарии — отдельным слоем, без смешивания с НПА.

## Два потока

| Поток | Назначение | Результат |
|---|---|---|
| Collector | обнаружение, получение и первичная разметка | карточка источника, URL, файл/снимок, дата доступа |
| Verifier | проверка органа, реквизитов, редакции, отмены и связей | подтвержденный статус, замечания, связь с другими актами |

Один и тот же агент не переводит собственную находку в `version_verified` без независимой проверки.

## Конвейер

```text
обнаружение → официальный URL → реквизиты → получение
→ SHA-256 → извлечение текста → разбиение на нормы
→ связи «изменяет/исполняет/отменяет/разъясняет»
→ экспертная проверка → публикация в базе знаний
```

## Статусы

- `discovered` — источник найден, реквизиты требуют проверки;
- `official_url_verified` — подтверждена официальная страница;
- `version_verified` — проверены редакция, действие и изменяющие акты;
- `acquired` — допустимая копия или снимок помещены в корпус;
- `hashed` — рассчитана контрольная сумма;
- `parsed` — текст извлечен и структурирован;
- `linked` — построены связи;
- `rejected` — источник отклонен с причиной.

## Правила хранения

- GitHub хранит метаданные, разрешенные текстовые снимки, контрольные суммы и производные знания.
- Крупные бинарные файлы не кладем бесконтрольно в Git: для них нужен Git LFS или объектное хранилище.
- Платные базы, персональные данные, утечки и материалы с неясными правами не копируются.
- Для каждого утверждения сохраняются источник, дата доступа, фрагмент/норма и уровень уверенности.
- Доступ к открытой папке не означает, что в нее допустимо помещать чувствительные данные.
