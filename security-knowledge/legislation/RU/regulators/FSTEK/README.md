## Change lineage

Изменяющие приказы не дублируются по каталогам. Каждый хранится как самостоятельный нормативный объект и связывается отношением `AMENDS` с одним или несколькими документами.

Примеры уже установленных связей:

- FSTEK-31-2014 ← FSTEK-49-2017, FSTEK-138-2018, FSTEK-46-2021.
- FSTEK-235-2017 ← FSTEK-64-2019, FSTEK-69-2023.
- FSTEK-239-2017 ← FSTEK-138-2018, FSTEK-60-2019, FSTEK-35-2020, FSTEK-159-2024.

## Принцип доказательности

Текст нормы и реквизиты источника являются фактами. Интерпретации, веса, applicability и архитектурные выводы являются версионируемой аналитикой. Изменение аналитической модели не переписывает первичный нормативный слой.
