- **Title:** Values of floating-point types
- **Document:** P3938R1
- **Date:** 2026-02-20

## Relevant use

Shows that C++ floating-point value and language semantics require language-specific interpretation and that ISO/IEC 60559 adherence should not be casually treated as a blanket guarantee for all C++ expression behavior.

## Caution

This is a WG21 proposal/paper, not itself the published ISO C++ standard. Use it to understand current standards work and ambiguity, while normative production claims should be traced to the applicable published standard and implementation documentation.
