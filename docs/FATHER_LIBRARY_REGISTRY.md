# FATHER Library Registry

Центральный реестр внешних библиотек, справочников, корпусов и коллекций, которые могут использоваться продуктами FATHER как источники кандидатов на знания.

## Правило доверия

Запись в этом реестре не означает автоматического признания материала достоверным.

```
DISCOVERED
→ CANDIDATE
→ PRIMARY_SOURCE_CHECKED
→ VERSION_CHECKED
→ SAFETY_REVIEWED
→ LAB_TESTED
→ VERIFIED / REJECTED / DEPRECATED
```

Критически значимый материал не получает статус `VERIFIED` только на основании популярности, количества GitHub stars или утверждения автора.

#### Ценность для FATHER

- обнаружение полезных технических инструментов;
- пополнение учебных маршрутов;
- кандидаты для карточек Linux, сетей, TLS, DevOps, OSINT и пентеста;
- исходный материал для шпаргалок;
- обнаружение официальной документации и более глубоких руководств;
- пример крупной человекочитаемой коллекции технических знаний.

#### Обязательная обработка материала

Для каждой извлечённой команды, рекомендации или ссылки фиксировать:

- стабильный ID;
- исходную запись;
- дату извлечения;
- тематику;
- заявленное назначение;
- поддерживаемые ОС и версии;
- первичную официальную документацию;
- необходимые права;
- входные данные;
- ожидаемый результат;
- побочные эффекты;
- риск;
- процедуру отката;
- лабораторный тест;
- результат проверки;
- срок повторной проверки;
- reviewer;
- итоговый статус.

#### Политика безопасности

Особо опасными считаются:

- команды с административными правами;
- `curl | bash` и аналоги;
- изменение firewall, SSH, TLS и маршрутизации;
- операции с дисками и файловыми системами;
- удаление и массовое изменение файлов;
- изменение прав и владельцев;
- загрузка и запуск неизвестных бинарных файлов;
- сканирование внешних систем;
- работа с паролями, токенами и ключами;
- offensive security и exploitation.

Такие материалы допускаются только в изолированной лаборатории и в пределах законно разрешённого тестирования.

#### Целевая цепочка преобразования

```
The Book of Secret Knowledge
→ discovery record
→ candidate knowledge card
→ official primary source
→ version and applicability check
→ safety review
→ reproducible lab fixture
→ verified result
→ FATHER technical knowledge node
```

## План дальнейшего расширения реестра

Следующими категориями должны стать:

1. официальная нормативная база;
2. стандарты и RFC;
3. официальная документация производителей и open-source проектов;
4. NIST, MITRE, OWASP и другие профильные каталоги;
5. книги и учебные курсы;
6. научные статьи;
7. практические лаборатории;
8. наборы тестов и benchmark;
9. incident/postmortem collections;
10. curated lists с обязательным пониженным уровнем начального доверия.
