# Public regulatory automation contour

This repository publishes only the engineering outline, sanitized schemas, tests,
and aggregate progress reports for a traceable compliance knowledge system.

The local knowledge base, source documents, extracted full text, evidence,
organization-specific mappings, graph topology, edge weights, prompts, and
operational agent instructions remain on the workstation and are not published.

## Processing model

`official source → edition → atomic requirement → applicability → control → checklist → role → evidence → test → finding → remediation`

Planned contours are processed in this order:

1. personal data;
2. critical information infrastructure;
3. electronic signatures and powers of attorney;
4. government information systems;
5. cryptographic protection;
6. general information security;
7. protected-secret regimes and related domains.

Bank secrecy is intentionally scheduled as a later independent phase.

## Publication boundary

Public artifacts may describe what the system does and report aggregate progress.
They must not disclose source texts, local filesystem paths, evidence contents,
private graphs, weights, internal matching logic, or organization-specific gaps.
