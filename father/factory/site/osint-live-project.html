10 — Architecture Governance

PR / Material Change ↓ Change Impact ↓ Architecture Conformance ├─ PASS → Test/Security Evidence → Baseline ├─ REWORK ├─ ADR_REQUIRED └─ DEBT_ACCEPTANCE_REQUIRED → Debt Register

Debt отделён от defect/risk/feature. Старые исправленные дефекты не сохраняются искусственно как долг.

11 — Integration Architecture

CURRENT DEV Analyst → ResearchTask → OSINTAgent → Collector → Transport ↓ MaterialStore ↓ MaterialPackage CANDIDATE PROD ASYNC Task Client → Gateway → Durable Queue → OSINT Worker → Source/Legacy Gateway ↓ Evidence Store ↓ Result Event / DLQ

Broker активируется только при доказанной потребности в durable buffering, replay, backpressure, long-running jobs или independent scaling.

12 — Data Architecture

Sources / Stream + Batch ↓ Source Observation + Provenance ↓ Raw / Original Zone ─────→ Metadata Catalog ↓ Parse / Normalize ↓ Chunk / Enrich ├─ Lexical Index ├─ Vector Index [conditional] └─ Graph [conditional] ↓ Retrieval → Analyst → Review → Knowledge Candidate → Gate

Raw first. Original evidence survives parser/model/index upgrades. Vector/Graph/Feature Store are conditional storage layers, not mandatory decorations of an AI stack.

Storage roles

Raw evidence

Object storage / Data Lake class candidate.

Metadata

Relational/catalog candidate.

Semantic retrieval

Vector only after eval.

Relations

Graph only when graph queries justify.

Feature Store

Only when one model uses shared offline/online features.
