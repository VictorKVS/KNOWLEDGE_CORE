Урок 09 — текущее решение

Для текущей PoC/MVP semantic-model стадии: hosted LLM API через заменяемый Model Gateway только для данных, разрешённых к внешней обработке. Sensitive/UNKNOWN evidence наружу не уходит. Production self-hosting/cloud/on-prem решение откладывается до измеренных workload, quality, SLO и TCO.

Hosted API

Быстрый старт, минимальный CAPEX, зависимость от провайдера/условий.

Cloud GPU

Контроль модели, но собственная эксплуатационная ответственность.

On-prem GPU

Сильный контроль данных, CAPEX и utilisation risk.

Hybrid

Гибкость, но дополнительная маршрутизация и governance.
