Зачем этот слой

FATHER не принимает «модель отвечает красиво» как доказательство качества. Semantic/RAG/agent/document-worker изменение продвигается только через versioned dataset, evidence/security checks, operational metrics и человеческое решение.

Пять слоёв качества

Deterministic

Schema, required fields, citation/evidence ref resolution, tool allowlist, budget/cycle limits, dataset integrity.

Retrieval

Expected evidence coverage, Recall@K, Precision@K, MRR/NDCG where meaningful.

Generation

Faithfulness, groundedness, Answer Relevancy, completeness, unsupported-claim rate, correct UNKNOWN.

Security

Prompt injection, retrieval poisoning, fabricated citations, tool privilege escape, secret/data exfiltration.

Operational

p50/p95/p99, throughput, queue time, reliability, GPU/VRAM when local, cost/query and cost/accepted result.

Eval Dataset

CALIBRATION

Настройка метрик/rubrics и human calibration.

REGRESSION

Стабильный набор для CI и promotion.

HOLDOUT

Не используется для рутинной подгонки.

SECURITY

Adversarial corpus: injection, poisoning, tool abuse, evidence fabrication.

PRODUCTION SHADOW

Только если data policy допускает approved/sanitized реальные кейсы.

CI tiers

Tier 0

FAST

Deterministic checks на каждом material change.

Tier 1

COMPACT

Tier 2

FULL EVAL

Перед promotion semantic route.

Tier 3

SECURITY

Retrieval/agent/tool/provider/sensitive-data changes.

Tier 4

LOAD + COST

Перед Production/hosting decision.

Hard blocks

fabricated material source/citation unsupported high-impact claim retrieved content changes system/tool policy prohibited data sent to external provider unauthorized tool execution material claim without resolvable evidence critical security regression

Hard block нельзя «перекрыть» хорошим средним score, низкой стоимостью или большинством голосов моделей.

Связь с Model Zoo

Champion / Challengers / Judge оцениваются не по бренду модели, а по накопленной телеметрии: human acceptance, unsupported claims, useful challenge rate, false challenges, judge↔human agreement, rework и cost per accepted result.

Model Zoo run ↓ Quality Gate evidence ↓ Human review ↓ Accepted / rejected claims ↓ Capability telemetry ↓ Next model routing decision
